Devices: 18 (8 nMOS, 10 pMOS), measured at 77 K; simulator: NGSpice 41; model: standard BSIM4, only parameter values change

Start: paper's 77 K card files with every tuned multiplier set to 1; 3 random starts per device

All-device / combined RRMS: paper card 0.2751 / 0.2595; our 7-parameter card 0.1546 / 0.1458; our 45-parameter card 0.1094 / 0.1026

2026-10-28 (run I25-1)

This deck covers fitting BSIM4 card parameters to measured SkyWater 130 nm I-V data at 77 K. The model is the standard BSIM4 in NGSpice 41; only parameter values change. The fit starts from the paper's 77 K card files with every tuned value removed. There are 18 measured devices, 8 nMOS and 10 pMOS. Every number comes from NGSpice 41 runs scored with the paper's RRMS metric. Two parameter sets are fitted: the paper's 7 parameters and a 45-parameter set from a sensitivity screen.
