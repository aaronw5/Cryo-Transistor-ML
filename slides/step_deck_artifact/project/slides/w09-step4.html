Step 4: local refinement (least squares)

  • Change each parameter slightly, run NGSpice, get the slope of the error
  • Step to parameter values with lower squared current error; repeat
  • Per start and round: about 165 NGSpice runs (7 parameters), 478 (45)
After the global search, a least-squares method refines the best card. It changes each parameter by a small amount, runs NGSpice, and uses the change in error as a slope to pick the next step. This needs far fewer runs than the global search. The squares in the figure show the result after each refinement.
