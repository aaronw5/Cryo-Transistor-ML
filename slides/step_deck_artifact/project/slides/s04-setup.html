Step A fits the card in NGSpice. The fit starts from the paper's card files with every tuned multiplier set to 1, so no tuned value from the paper is used. Each device gets three random start points inside the box. Each start runs three rounds of CMA-ES followed by TRF; rounds 2 and 3 re-center the box on the previous card and halve its width. A finite-difference polish follows. Per device, the start with the lowest RRMS on that device's data is kept, and that card is refit once more by TRF. This final card is the card in every result table and I-V figure. The next slide gives the reason for each choice and the evidence from this run.
