  • Redraw rule: a start is redrawn until NGSpice simulates every scored curve; redrawn on 19 of 54 device-start pairs (7p), 22 of 54 (45p); at most 5 / 12 redraws
  • Cause: a low U0 draw plus negative size terms LU0 / WU0 / PU0 in the bin gives effective u0 <= 0; BSIM4 aborts the run
  • CMA-ES = evolutionary search; TRF = trust-region least squares; 1 NGSpice call = 1 run of all measured biases of 1 device
Step A fits the card in NGSpice. The fit starts from the paper's card files with every tuned multiplier set to 1, so no tuned value from the paper is used. Each device gets three random start points inside the box. Each start runs three rounds of CMA-ES followed by TRF; rounds 2 and 3 re-center the box on the previous card and halve its width. A finite-difference polish follows. Per device, the start with the lowest RRMS on that device's data is kept. Some random draws give a card NGSpice cannot run: a low U0 combined with the bin's negative length, width and area terms gives a non-positive effective mobility, and BSIM4 stops. Such a start is redrawn from the same random stream.
