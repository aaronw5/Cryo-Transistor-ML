The first arm fits exactly the paper's seven parameters. The second arm fits the set chosen by a sensitivity screen run on the multiplier-1 card: every one of 115 BSIM4 candidates is changed by ten percent and kept if the simulated current moves by more than one part in ten thousand of the measured mean current on any device. 45 parameters pass, 42 of them shared with the 43-parameter set used in the earlier run. Parameters whose stock value is zero in a device's bin are not fitted, so each device fits 39 to 42 of the 45.
