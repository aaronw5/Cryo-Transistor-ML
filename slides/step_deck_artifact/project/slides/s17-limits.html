All RRMS values in this deck measure how well the cards and g fit the 18 measured devices; there is no separate test set, because the goal is to fit measured data. The design of g was chosen on these same devices in earlier runs, and the box widths were set with the paper's multiplier range known. Some random starts had to be redrawn because NGSpice could not run them. The Verilog-A element checks label both cards with g not deployable under the I17-1 rule (two devices). Step A has not been compared with other fitting methods at the same budget.
