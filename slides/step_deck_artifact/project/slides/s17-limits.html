All RRMS values in this deck measure how well the cards fit the 18 measured devices; there is no separate test set, because the goal is to fit measured data. The fit settings were chosen on these same devices in earlier runs, and the box widths were set with the paper's multiplier range known. Some random starts had to be redrawn because NGSpice could not run them. The pMOS Id-Vg at 0.01 V carries the largest part of the remaining error, and the measured sweeps disagree at that bias. The fitted numbers are bin base values; whether the resulting effective values are in a physical range has not been checked. Step A has not been compared with other fitting methods at the same budget.
