Step 3: global search (CMA-ES)

  • CMA-ES: samples many parameter sets, moves the sampling toward lower error
  • Per start and round: about 3,000 NGSpice runs (7 parameters), 8,000 (45)
  • Figure: one pMOS, 45 parameters; circles = after global search
The global search uses CMA-ES, an evolution strategy. It samples many parameter sets inside the range, and moves its sampling distribution toward the sets with the lowest error. It needs no slopes. In this pMOS example the first global search lowers the RRMS from about 1 to about 0.12 to 0.17.
