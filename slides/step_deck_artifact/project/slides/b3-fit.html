Card fit loop

1. Card parameters p

2. NGSpice run: simulated curves

3. RRMS vs measured curves

4. Optimizer: new p

  • Objective: device RRMS; 1 NGSpice call = 1 simulation of all measured curves of 1 device
  • Box: allowed range per parameter; Latin hypercube: spread-out random sample of the box
  • CMA-ES: evolutionary search (sample p, keep best, update the sampling distribution)
  • TRF: trust-region least squares (SciPy least_squares); FD: finite-difference Jacobian, 1 call per parameter per step
Fitting a card means repeating this loop: write parameter values into the card, run NGSpice at the measured biases, score RRMS against the measurements, and let an optimizer propose new values. Each pass costs one NGSpice call per device. Two optimizers are used: CMA-ES for a global search inside the box, then TRF for local least squares with a finite-difference Jacobian. Cost is counted in NGSpice calls throughout.
