Some inputs to this pipeline come from the paper's card rather than from the stock card. The card file itself sets the 77 K nominal temperature. One device, pMOS L 0.35 x W 1.6 um, starts from five of the paper's tuned multipliers. The 43-parameter set was screened around the paper card, and the box width covers the range of the paper's multipliers. "Not measured" means the effect of that input on the result has not been tested.
