With the paper's seven parameters the error stops falling at 0.1546. For the second run we choose more parameters with a screen: each of 115 BSIM4 parameters is changed by ten percent, and it is kept if the simulated current changes by more than one part in ten thousand of the measured current. 45 pass. A parameter whose value is zero in a device's card stays zero, and the fit code also keeps values below about 1e-14 fixed: UB on all devices, B1 and CDSC on some. So 37 to 41 are fitted per device. Compared with an earlier screen that gave 43, three parameters were added and one removed.
