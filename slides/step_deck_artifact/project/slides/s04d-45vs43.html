The 45-parameter set comes from the same sensitivity screen that gave the earlier 43, re-run around the multiplier-1 card instead of the paper card. 42 parameters are in both sets. Three are added: CDSC and DVT0W pass the threshold on one device each, just above the limit, and PDIBLC1 passes on the five short pMOS devices. CDSCD falls below the threshold and is dropped. Because the fit box is logarithmic, a parameter whose value is zero in a bin stays at zero: PDIBLC1 is zero in every pMOS bin, so it is fitted only on the nMOS devices, although the screen found it on pMOS; DVT0W is zero in every nMOS bin and is fitted only on pMOS.
