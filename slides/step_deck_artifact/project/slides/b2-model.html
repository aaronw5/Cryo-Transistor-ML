Card, NGSpice, RRMS

Card

BSIM4 parameter file, e.g. VTH0 = threshold voltage

NGSpice

circuit simulator, run at 77 K

Simulated curves

Id at the measured biases

Measured curves

11 per device

RRMS

relative RMS current error

  • c = scored curve, n_c = its points, C = scored curves per device
  • Scored set: curves scored with the paper card, same for every row
  • All-device = mean of 18 devices; combined = (nMOS mean + pMOS mean) / 2
A compact model such as BSIM4 is a set of equations for Id as a function of the terminal voltages, size and temperature. The card is the file of parameter values for those equations; the foundry kit (PDK, here SkyWater sky130A) splits it into bins, one per L and W range. NGSpice evaluates the card at the measured biases. RRMS compares simulated and measured current curve by curve, normalized by the mean measured current, and averages over the device's curves. Two averages over devices are reported: all-device and combined.
