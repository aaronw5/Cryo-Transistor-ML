Glossary

Id, Vgs, Vds = drain current, gate and drain voltages

gm, gds = dId/dVgs, dId/dVds

BSIM4 = transistor compact model

Card = file of BSIM4 parameter values

Bin = card section for one L, W range

PDK = foundry model files

NGSpice = open-source circuit simulator

NGSpice call = 1 simulation of 1 device

RRMS = relative RMS current error (slide “Stock card, 77 K”)

All-device = mean over 18 devices

Combined = (nMOS mean + pMOS mean) / 2

Starting card = Step A output

Card refit = TRF fit of a held-out device

g = learned correction, I = I_card exp(g)

MLP = stacked weighted sums + nonlinear functions

lambda = penalty weight (V)

LODO = leave one device out

Fold = one LODO split

GMR = geometric mean of RRMS ratios

CMA-ES = evolutionary search

TRF = trust-region least squares

FD = finite-difference Jacobian

Verilog-A = language for analog device models

OSDI = compiled-model interface of NGSpice
