Step 1: start card

Input: paper card file with the tuned values removed (all multipliers = 1)

Does: uses its parameter values as range centres; range R1 per parameter (step 2)

Output: start card; all-device RRMS 12.1

  • Figure: one pMOS (L 0.35 um x W 5 um), start card vs measured
The start card is the paper's card file with every tuned value set back to its base value, that is, all multipliers equal to 1. It keeps the file's 77 K settings and contains no fitted value from the paper. Its all-device RRMS is 12.1. Its values are the centres of the parameter ranges.
