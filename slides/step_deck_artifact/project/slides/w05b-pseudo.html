for device in 18 devices:

# fitted separately

  for start in 1, 2, 3:

    range = R1 around the start card

# step 1

    x = random card in range

# step 2; redraw if NGSpice fails

    for round in 1, 2, 3:

      x = CMA-ES(device RRMS, x, range)

# step 3; 2,990 / 8,010 runs

      x = least_squares(residuals, x, range)

# step 4; 160 / 480 runs

      if round < 3: range = centred on x, half width

# step 5

    x = least_squares(residuals, x, range)

# 150 / 330 runs

  best = start with the lowest device RRMS

  final card = least_squares(residuals, best, range)

# 120 / 300 runs

  • Run counts: mean NGSpice runs, 7 / 45 parameters
  • range: allowed interval of each parameter, on a log scale
This is the same procedure line by line. The comments give the step number used on the following slides and the mean number of NGSpice runs. The range is the allowed interval of each parameter; it is narrowed in rounds 2 and 3.
