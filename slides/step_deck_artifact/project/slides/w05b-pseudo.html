Fitting procedure as pseudocode

for device in 18 devices:

  for start in 1, 2, 3:

    range = round-1 range

# step 1

    x = random card in range

# step 2

    for round in 1, 2, 3:

# round

      x = cmaes(loss=device_rrms, x, range)

# step 3; 2,990 / 8,010

      x = trf(loss=sum_sq_residuals, jac=fd, x, range)

# step 4; 160 / 480

      if round < 3: range = centred on x, half width

# step 5

    x = trf(loss=sum_sq_residuals, jac=fd, x, range)

# step 6, FD polish; 150 / 330

  best = start with lowest device_rrms

# step 7

  card = trf(loss=sum_sq_residuals, jac=fd, best, range)

# step 7, final FD refit; 120 / 300

  • The run counts are mean NGSpice runs per call, 7 / 45 parameters.
  • The range is the allowed interval of each parameter on a log scale.
fd: Jacobian by finite differences in NGSpice. trf: SciPy least_squares, method trf, 2 passes.
