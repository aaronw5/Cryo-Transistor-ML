Our workflow: nested loops

  • Run counts: mean NGSpice runs per box, 7 / 45 parameters
  • Total per device, 3 starts included: 28,953 / 77,696 NGSpice runs
  • Step slides use one pMOS (L 0.35 um x W 5 um), 45 parameters
Each device is fitted on its own. For each device there are three random starts. Each start goes through three rounds; a round sets the parameter range, runs the global search, then least squares. After round 3 one more least-squares pass follows. Then the start with the lowest RRMS is kept and refitted once more by least squares; the result is the final card. The numbers are mean NGSpice runs per box.
