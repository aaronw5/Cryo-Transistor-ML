Verilog-A element

  • I_card = card transistor current; I_ch = channel current of a card-transistor copy
  • Verilog-A = language for analog device models; compiled with OpenVAF, loaded through OSDI (NGSpice 41 compiled-model interface)
  • Checks (next slide): run I17-1 on the earlier 43p card + g (lambda 1 V); element RRMS = Python RRMS within 1.8e-4 per device
  • Not rerun on the I25-1 cards and g
To use g in circuit simulation, it is written as a Verilog-A element that adds (exp(g) - 1) times the channel current to the card transistor. The element is compiled with OpenVAF and loaded into NGSpice 41. The checks on the next slide were run on the earlier 43-parameter card with g; the same element code takes the new cards and g, but the checks have not been repeated for them.
