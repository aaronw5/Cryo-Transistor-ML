Verilog-A element

  • I_card = card transistor current; I_ch = channel current of a card-transistor copy
  • Verilog-A = language for analog device models; compiled with OpenVAF, loaded through OSDI (NGSpice 41 compiled-model interface)
  • g: trained on all 18 devices, lambda = 1 V; 43p card fit + g RRMS 0.0696 in Python and in the element deck
  • Per-device difference, element deck vs Python: max 1.8e-4; label (I17-1): deployable with restrictions
To use g in circuit simulation, it is written as a Verilog-A element that adds (exp(g) - 1) times the channel current to the card transistor. The element is compiled with OpenVAF and loaded into NGSpice 41. Run on the measured biases, it gives the same all-device RRMS as the Python model, 0.0696, with per-device differences up to 1.8e-4. The I17-1 checks on the next slide label it deployable with three restrictions.
