Step 2: three random start points

Input: start card and range R1: VTH0 and added parameters 1/3-3 x, other 6 of the 7: 1/100-100 x

Does: draws each free parameter at random (uniform on a log scale); redraws if NGSpice fails

Output: 3 start cards per device

  • Figure: starts 1 and 2 give almost no current (RRMS 1.15); start 3: 42.5
  • Reason for 3 starts: a search from one point can stop in a local minimum
Each device gets three random start cards inside range R1. A parameter is drawn uniformly on a log scale between its lower and upper limit. If NGSpice cannot simulate the card, for example because the effective mobility becomes negative, a new card is drawn. In the example, starts 1 and 2 give almost no current and start 3 gives a current with the wrong shape.
