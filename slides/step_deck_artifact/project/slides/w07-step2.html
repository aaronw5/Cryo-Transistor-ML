Step 2: three random start cards

Inputstart card; range VTH0 and 38 added parameters 1/3-3x, other 6 of 7 1/100-100x
Output3 random start cards per device
  • Each free parameter gets a random value between its limits, uniform on a log scale.
  • NGSpice simulates the card; if a scored curve fails, a new card is drawn (mean 1.6 / 2.2 runs per start).
  • For the example pMOS, starts 1 and 2 give currents below 1e-11 A (device RRMS 1.15) and start 3 has device RRMS 42.5.
