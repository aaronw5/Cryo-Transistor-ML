  • Each parameter drawn at random in its range, uniform on a log scale
  • Reason: a search from one point can stop in a local minimum
  • If NGSpice cannot simulate a start (mobility below 0), a new one is drawn
  • New draws needed: 19 of 54 starts (7 parameters), 22 of 54 (45)
Each device gets three random start points inside the allowed range. Several starts are used because a search from a single point can end in a local minimum. Some random values give a card that NGSpice cannot simulate, because the effective mobility for that transistor size becomes negative; such a start is replaced by a new random draw.
