One NGSpice run

  • One run simulates all 11 curves of one device for one card.
  • CMA-ES uses one number per run: the device RRMS.
  • TRF uses one residual per measured point.
Point residual = (I_sim - I_meas) / mean |I_meas| of its curve, divided by the square root of (points in the curve x curves of the device). The sum of squared residuals then equals the mean squared curve RRMS. A curve NGSpice cannot simulate counts as RRMS 10.
